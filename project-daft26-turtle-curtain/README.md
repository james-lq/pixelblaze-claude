# Daft26 Turtle Curtain

Simple "sparkle curtain" installation.

## Hardware

- 50 LEDs on a flexible wire

- PixelBlaze v3.

## Pixel Map

- Hanging from a bar in lengths of 10 pixels, forming a rough grid of 10 columns by 5 columns
- Pixel index zero starts at upper left. LED string zigzags up and down to form columns. Pixel index 49 at the lower right.

## Patterns

- Generate a pattern that fills the 2D mapped space with sparse "stars" that twinkle a bit. Prefer bright cool color pallete.
